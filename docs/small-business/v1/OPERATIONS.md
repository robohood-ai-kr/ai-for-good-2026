# RoboHood 소상공인 중심 운영 원칙 v1

- 기준일: 2026-09-18
- 기준: [제품 기획서](PROJECT_PLAN.md) · [MVP 구현 명세](MVP_SPEC.md)
- 상태: 실증 전 운영 설계. 제휴·고용·계약·지원금·안전 적합성이 확정된 것이 아니다.

## 1. 역할과 책임

| 역할 | 책임으로 설계할 범위 |
|---|---|
| 데이터 요청 기업 | 사용 목적·명세·검수 기준, 비용 부담 조건, 승인된 범위의 데이터 이용 |
| 소상공인·현장 제공자 | 수집 장소·시간·업무·노출 금지 정보 확인, 현장 담당자 지정 |
| 수집 전문기업·운영팀 | 교육·과제별 적격 평가·감독·장비·품질·보상 운영과 문제 대응 |
| 청년 Physical AI 현장 전문인력 | 승인된 프로토콜에 따른 촬영·기록·시연, 오류·위험 시 중단·보고 |
| 검수 담당자 | 명세와 권리에 따른 승인·반려, 구체적 보완 사유·이력 기록 |
| 플랫폼 운영자 | 접근권한·기록·문의·사고 접수 경로 관리 |

소상공인을 자동으로 청년의 고용주로, 청년을 매장의 일반 영업 인력으로 취급하지 않는다. 실제 고용·도급·보상·보험·사고 책임은 운영 주체와 계약 구조를 정한 뒤 검토한다. 고객 주문 처리나 상시 부족 인력을 데이터 수집 명목으로 대체하지 않는다.

## 2. 인력 명칭과 진입 조건

공통 상위 명칭은 **청년 Physical AI 현장 전문인력**이다. 프로젝트 내부의 인력 분류이며 공인 자격을 뜻하지 않는다.

- **현장 데이터 수집:** 청년 Physical AI 현장 전문인력이 첫 MVP에서 맡는 세부 직무다. 촬영·조건 기록·작업 구간 라벨 초안·보완을 수행한다. 텔레오퍼레이션은 별도의 장비·과제별 교육과 감독을 갖춘 경우에만 배정한다.
- **현장 기술지원 인력:** 장비 설치·점검·연동 등 별도 기술 역량과 승인이 필요한 직무다. 초급 수집 인력의 의무가 아니다.
- **FDE · 현장 적용 엔지니어:** 요구 정의·데이터·모델·장비 통합과 배포 문제를 해결하는 전문 직무다. 전문기업의 담당 영역이며 청년의 자동 승급 단계나 첫 MVP 일자리로 약속하지 않는다.

교육 → 모의 실습 → 과제별 적격 확인 → 감독하의 유급 작업 순으로 진입을 설계한다. ‘저숙련자도 가능’은 무교육·무감독을 뜻하지 않는다. 반복 수행에도 신체 부담·휴식·작업환경을 확인한다.

## 3. 유급 업무와 경력 기록

- 배정 전에 업무 범위, 준비·교육·실작업·보완에 대한 보상 기준, 예상 시간, 지급 주체·일정을 확인한다.
- 검수 반려만으로 무제한 무급 재작업을 요구하지 않는다. 재작업 범위·보상·이의 제기 경로를 사전에 정한다.
- 작업시간·검수·교육 이력과 실제 지급 확인을 분리한다. 모의 화면 수치와 실제 지급 실적을 혼합하지 않는다.
- 경력에는 참여 과제·맡은 직무·교육·확인한 기술·검수 결과를 기록한다. 포트폴리오 공개는 현장·데이터 이용 권한 안에서 허용한다.
- 단가·계약 형태·참여 조건은 미정이다. 일자리 수·취업·FDE 전환·지역 정착을 보장하지 않는다.

## 4. 현장 안전과 데이터 권리

첫 데모는 고객이 없는 식당의 빈 식기 분류 또는 동네마트의 모형 냉장상품 진열을 사용하며, 동의한 수행자만 포함한다. 화기·칼·뜨거운 액체·깨진 식기·무거운 물체·실제 설비 조작·고객 응대는 제외한다. 실제 매장으로 확장하기 전에 영업 방해·동선·장비·촬영 범위를 현장 담당자와 검토한다.

사람의 영상에는 얼굴·음성·주변 인물과 매장의 영업 정보가 포함될 수 있다. 수집 전에 목적·구역·대상·이용·보관·삭제 범위를 정하고, 승인되지 않은 촬영은 중단한다. 첫 실증은 고객과 비참여 직원의 노출을 피할 수 있는 공간·시간을 우선한다. 실제 영상·개인정보·정확한 주소를 공개 저장소나 생성 프롬프트에 넣지 않는다.

원본·비식별 가공본·승인 데이터셋을 구분하고, 최소 권한으로 접근한다. 수집 허용은 모델 학습·외부 공유·재판매의 포괄 허용이 아니다. 제공자·수행자·요청자의 권한과 철회·삭제 요청 처리 가능 범위는 계약·운영 검토로 정한다.

## 5. 공공지원과 민간 책임

서울시 등에는 청년 교육, 공동 장비, 안전한 실습 공간, 초기 유급 실증과 기업 연결을 제안한다. 학교의 모의 교육과 실제 현장 근로를 구분하고 참여 조건을 별도로 검토한다. 예산·기관 참여는 미확정이다.

지속적인 수집 수요와 비용 부담은 데이터 요청 기업을 중심으로 검증한다. 기존 공급업체의 설치·연동·유지보수 책임을 공공사업이나 초급 청년에게 넘기지 않는다. 공공 지원 종료 뒤의 수집·감독·검수·보상 비용까지 확인한다.

## 6. 실증 판단

유급 작업시간·실제 보상, 검수 통과율·보완 시간, 안전 중단·해결 이력, 재참여·후속 직무 연결을 측정한다. 측정 기간·분모와 실제/모의 여부를 남긴다. 교육 이수자·영상 업로드·배정 건수를 실제 고용 실적으로 대체하지 않는다.

수요·현장 승인·감독·보상·이용 조건을 충족하지 못하면 실제 배정을 중단하고 모의 검증만 수행한다. 상세 미정 사항은 [MVP 확인 표](MVP_SPEC.md#6-미정-사항--확인-방법)에서 관리한다.
