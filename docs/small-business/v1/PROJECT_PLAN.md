## 1. 해결하려는 문제

청년에게는 교육 이후 실제 보상을 받으며 기술 업무와 경력을 경험할 기회가 필요하다. 로봇·AI 기업에는 특정 업무·환경·품질 조건을 충족하는 데이터가 필요하다는 수요 가설이 있다. 소상공인 현장은 일상적인 물체 취급·정리 작업을 제공할 수 있지만, 촬영·데이터 이용·현장 부담을 개별적으로 협의하기 어렵다.

로보후드는 필요한 데이터를 먼저 정의하고, 이를 수집할 현장과 교육받은 수행자를 연결한다. 데이터를 무작정 모은 뒤 판매처를 찾거나 소상공인이 로봇을 구매해야만 참여할 수 있는 모델이 아니다.

## 2. 참여자와 비용 구조 가설

| 참여자 | 제공하는 것 | 받는 가치·책임 |
|---|---|---|
| 로봇·AI 기업·연구팀 | 수집 목적·명세·검수 기준, 수집비 지불 수요 | 조건에 맞고 출처·이용 권한이 명확한 데이터. 구매 의사는 검증 필요 |
| 소상공인·현장 제공자 | 업무 설명, 허용된 공간·소품·촬영 범위 | 협의한 현장 제공 대가·업무 기록 등. 로봇 도입·매출 상승을 보장하지 않음 |
| 수집 전문기업·운영팀 | 장비·프로토콜, 교육·감독·검수 | 수집 과제 수행 대가와 품질·안전·보상 관리 책임 |
| 청년 Physical AI 현장 전문인력 | 교육·자격 범위의 데이터 수집·기록·보완 | 유급 작업과 검증 가능한 수행 이력. 기본 직무는 데이터 수집 오퍼레이터 |
| 지자체·교육기관 | 협의 가능한 교육·공동 장비·실습 공간 | 초기 진입 장벽 완화와 일자리 실증. 참여·예산 미확보 |

기본 비용 가설은 요청 기업이 수집·검수 대가를 지불하고, 수행팀이 청년 보상·감독비·장비비·현장 제공 대가를 운영하는 구조다. 플랫폼의 수익은 과제 운영·검수 관리 대가를 우선 검증하며 수수료율은 정하지 않는다. 소상공인을 자동으로 데이터 구매자나 청년 고용주로 취급하지 않는다.

## 3. 대상과 첫 실증

- 지역: 서울의 한 생활권과 협력 매장 또는 공동 실습 공간을 첫 실증 후보로 둔다. 특정 자치구·매장·기관은 미정이다.
- 업무: 식당·카페의 정리 작업 중 교육 후 반복 가능한 저위험 업무 하나를 선정한다. 조리 기술 전체나 매장 노동 전체를 초급 업무로 보지 않는다.
- 대표 데모: 모의 카페 작업대에서 빈 트레이에 가벼운 비파손 컵을 정해진 위치로 정리하는 작업. 뜨거운 물·칼·화기·고객 응대는 제외한다.
- 촬영: 동의한 수행자의 1인칭 영상과 작업 구간·성공 여부·환경 조건을 기록한다. 실제 영업시간 고객 촬영은 첫 데모에 포함하지 않는다.

요청 기업이 사용할 목적과 샘플 수용 기준을 먼저 확인한다. 이 데모는 영상 기반 작업 구간·행동 이해용 데이터 수집 흐름의 검증이며, 영상만으로 로봇의 제어 정책이나 RFM 학습 데이터가 완성됐다고 주장하지 않는다.

## 4. 핵심 제품 흐름과 수집 방식

`데이터 요청 → 현장·수집 조건 협의 → 교육·자격 확인 → 유급 업무 배정 → 수집 → 검수·보완 → 승인 데이터 제공 → 수행·보상 이력`

| 수집 방식 | v1 취급 | 조건 |
|---|---|---|
| 사람의 작업·1인칭 영상 | 첫 MVP의 한 가지 수집 방식 | 과제·촬영 프로토콜·동의·작업 구간·품질 기준 필요 |
| 텔레오퍼레이션 | 장비·파트너 확보 후 별도 실증 후보 | 실제 로봇 상태·행동·시간 동기화, 교육·감독·정지 조건 필요. 게임 경험만으로 적격 판정하지 않음 |
| 시뮬레이션 | 전문팀의 후속 데이터 보완 수단 | 실제 수집과 출처를 구분. 시뮬레이션 제작을 곧바로 초급 청년 일자리로 계산하지 않음 |

RFM 학습·미세조정, 로봇 하드웨어 선정과 현장 배포는 수요 기업·전문기업의 담당 영역으로 둔다. 플랫폼은 데이터의 사용 목적과 적용 피드백·재수집 요청을 연결하되 이 전 과정을 직접 구현하지 않는다.

## 5. v1 MVP 경계

요청자 하나·모의 현장 하나·작업 하나·영상 수집 방식 하나로 시작한다. 요청 명세, 현장 조건, 교육·보상 조건, 배정, 영상·메타데이터 업로드, 승인·반려, 데이터셋 버전·접근권한, 작업시간·보상 확인 기록을 연결한다.

로봇·POS 쇼핑, 음성 매장 제어, 자체 RFM 학습, 실제 로봇 배포·원격 관제, 자동 결제·지급은 제외한다. 화면에 표시하는 지급 내역은 실제 지급과 모의 기록을 구분한다. 독립 데이터 플랫폼으로 구현하며 KAMP 등 외부 계정·API를 필수로 두지 않는다.

## 6. 청년 일자리와 정책 연결

상위 명칭은 **청년 Physical AI 현장 전문인력**, 첫 직무는 **데이터 수집 오퍼레이터**다. 현장 기술지원과 FDE는 별도 역량·책임이 필요한 전문 직무이며 모든 참여자가 수행하거나 자동 승급하는 과정으로 만들지 않는다.

서울시 등에는 교육·공동 장비·안전한 실습 공간·초기 유급 실증을 제안한다. 상시 설치·연동·유지보수의 기업 책임을 청년 지원사업으로 넘기지 않는다. 학교 교육은 모의 실습으로 구분하며 실제 현장 참여 조건은 별도로 검토한다.

주요 검증 지표는 실제 유급 작업시간·보상, 검수 통과율·보완 시간, 재참여·후속 직무 연결이다. 교육 이수·가입자·업로드 수만으로 양질의 일자리 창출을 입증하지 않는다. 수요·보상·안전·데이터 사용 조건을 합의하지 못하면 실제 현장 배정을 시작하지 않는다.
