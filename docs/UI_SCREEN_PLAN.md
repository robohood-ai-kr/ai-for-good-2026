## 화면 구성 원칙

제조기업 또는 AI 기업·연구팀이 과제를 요청한다. 제조기업은 현장을 제공하고, 데이터 수집 전문기업·팀은 수행 계획·장비·검수 책임을 맡는다. 청년 Physical AI 현장 전문인력은 직무별 교육·적격·감독·보상 조건에 맞는 업무를 수행한다. 데이터 수집 오퍼레이터, 현장 기술지원 인력, FDE를 구분하며 자동 승급 체계로 표현하지 않는다. 과제마다 요청자·현장 제공자·수행팀·담당자를 구분한다.

[제품 기획서의 핵심 흐름](AI_FOR_GOOD_PROJECT_PLAN.md#4-핵심-제품-흐름)을 화면에 적용한다. 과제·데이터셋 버전·모델·장비·이벤트의 연결과 다음 행동을 추적할 수 있게 한다.

데스크톱은 개요 / 현장 탐색 / 현장 과제 / 데이터 / 모델 / 장비 / 배포·관제 / 현장 인력과 설정을 사용한다. 현장 탐색 메뉴는 21번 시안에 추가했으며 기존 20개 이미지의 내비게이션은 보존했다. 구현 시 공통 내비게이션에 반영한다. 모바일은 작업함 / 수집 / 경력 / 내 정보를 사용하며, 내 정보는 공통 로그인·설정 화면의 반응형 적용을 전제로 한다.

로그인, 시작 화면, 워크스페이스 설정은 사용 흐름을 완성하기 위한 UI 제안이다. 제조기업·AI 기업·수집 전문기업은 공통 작업 공간에서 과제별로 참여하며, 조직 유형과 데이터 권한을 구분한다. 별도 로그인 체계·요금·결제·데이터 거래는 확정하지 않는다.

대상은 지역 제조업이며 첫 실증 지역·협력사는 미정이다. 대표 데모는 RGB 이미지·정상/불량 라벨을 활용한 소형 부품 외관 검사다. 다른 센서·행동 데이터가 등장하는 화면은 후속 확장 예시이며 v1 MVP 필수 기능이 아니다.

## 시각적 방향

후속 디자인·개발은 [공통 디자인 기준 v1](../DESIGN.md)을 따른다. MUI의 업무용 대시보드 구성과 KRDS의 한글 가독성·접근성 원칙을 결합해 파랑·청회색·흰색을 사용한다. 제조업과 소상공인의 기능·메뉴는 합치지 않는다.

현재 PNG의 오프화이트 배경·차콜 본문·딥그린 행동·민트 선택 표시는 이전 시안의 색상이며 그대로 보존했다. 새 기준이 이미지에 적용되었다는 뜻은 아니다. 상태는 색만으로 전달하지 않고 문구를 함께 표시한다.

장비나 로봇의 장식보다 현재 상태와 다음 행동을 먼저 보여준다. 실제 사용을 가정한 읽기 쉬운 한국어와 여백을 사용한다. 모바일 수집 화면은 큰 버튼과 짧은 현장 체크를 우선한다.

각 이미지의 회사·이름·장비·날짜·통계·평가 결과는 예시이며 실제 운영 증거가 아니다. 제품 기획 버전 v1과 화면 속 데이터셋 v1.2·모델 v0.3은 서로 다른 버전이다. 이미지 내부의 작은 글자와 수치는 구현 명세로 사용하지 않고, 기획서와 화면 목적을 기준으로 구현한다.

## 21번 현장 탐색

과제를 이미 등록한 뒤 관리하는 04번과 달리, 21번은 요청자가 과제 등록 전에 현장과 가용 데이터를 찾는 진입 화면이다. 기존 제조공장 콘셉트 이미지의 지도·목록 구성은 활용하되 정부 기관 표시, 명장 수·평균 연령 등의 통계와 브랜드는 사용하지 않는다.

- 왼쪽 지도: 지역별 예시 현장 위치와 선택 표시. 실증 지역·협력사가 미정이므로 실제 주소나 운영 현황으로 제시하지 않는다.
- 오른쪽 목록: 현장명, 지역, 업종·공정, 데이터 종류, 수집 협의 상태. 지역·공정·데이터 종류 등으로 탐색한다.
- 선택 현장 상세: 공개 샘플, 촬영 구역·일정 협의 여부, 데이터 이용 조건을 확인한다. 비공개 데이터 접근 권한을 자동 부여하지 않는다.
- 주요 행동: ‘데이터셋 보기’ → 11번, ‘이 현장에 수집 요청’ → 선택 현장을 미리 채운 05번. 연결은 후속 구현 제안이며 현재 갤러리는 이미지 열람만 지원한다.
- 범위: 이 화면은 제조업 중심 v1의 예시다. 소상공인 중심 v1에는 별도 생활권·업무 탐색 요구사항을 둔다. 로봇·POS 구매, 결제·데이터 거래를 이 화면에 추가하지 않는다.

## 2026-09-18 글자 수정과 미반영 경계

- 20개 화면의 지정된 글자 영역만 교체했다. 08 수집 화면은 유지했다. 원본 PNG·초기 생성 프롬프트는 이력으로 남긴다.
- 01·07·18에는 ‘청년 Physical AI 현장 전문인력’을 명시하고, 공통 메뉴에서는 ‘현장 인력’으로 줄였다.
- 06·07·16·17·19·20의 수집 담당자를 배포 담당자와 구분했다. 14 배포 화면의 담당은 ‘현장 적용 FDE’로 명시했다.
- 07·17에서 교육·감독·보상 조건을 안내하고, 18의 자동 승급처럼 보이던 설명을 역량별 직무 선택지로 수정했다.
- **미반영:** 신규 직무 권한 설정, 보상·지급 이력, 교육 확인 입력 등 새 기능 전체를 기존 이미지의 글자 교체만으로 구현하거나 묘사하지 않았다. 후속 개발은 MVP 명세를 따른다.
- 사용법: 갤러리에서 화면을 확대하고 ‘수정 전 보기’로 원본과 비교한다. 문구·좌표·서체 설정은 변경 명세로 재현할 수 있다.

## 결과물의 용도

페이지별 구성, 정보 우선순위와 전체 분위기를 검토하기 위한 이미지다. 클릭 가능한 제품이나 로봇 제어 구현은 포함하지 않는다. 생성 이미지 간 세부 아이콘·글자·간격 차이는 후속 구현 시 공통 컴포넌트로 통일한다.
