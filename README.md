# AI for Good — 로보후드

산업현장 데이터셋을 자체 저장·관리하고 AI 모델·로봇 배포와 재수집까지 연결하는 독립형 Physical AI 데이터 플랫폼, 로보후드(RoboHood)의 개발 워크스페이스입니다.

## 🎯 고려사항

- 평가기준을 먼저 확인하고 결과물 구성에 반영한다.
- 서울시와 서울시교육청이 실제로 할 일이 무엇인지 명확하게 제시한다. 제안 범위는 "서울시" 단위로 맞춘다.
- 심사위원 구성을 파악하고, 그에 맞춰 발표의 강조점을 조정한다.
