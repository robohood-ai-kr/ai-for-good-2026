# RoboHood 제출용 실제 화면 캡처 v1

Milgram 제출 페이지의 **Submission images** 항목에 아래 순서대로 업로드하는 것을 권장합니다.

> 모든 이미지는 2026-09-18 [RoboHood production 배포본](https://robohood-v1.vercel.app/)을 1536×1024 웹 화면으로 직접 캡처한 것입니다. 1~9번은 초기 화면, 10번은 3단계 발표 흐름을 실제 클릭해 검수 승인과 지급 확인까지 반영한 화면입니다. 화면 속 현장, 작업, 보상 및 데이터 수치는 실제 운영 실적이 아닌 데모용 예시입니다.

| 순서 | 파일 | 제출용 설명 | 전달할 메시지 |
| --- | --- | --- | --- |
| 1 | `01-robohood-overview.png` | RoboHood 서비스 개요와 전체 순환 구조 | 지역 소상공인의 일을 Physical AI 학습 데이터로 전환하고 청년 기술 일자리를 만듭니다. |
| 2 | `02-field-explorer.png` | 지도 기반 우리 동네 수집 현장 탐색 | 청년이 가까운 소상공인 현장과 필요한 작업을 발견합니다. |
| 3 | `03-task-detail.png` | 식당 테이블 정리·식기 분류 작업 상세 | 수집 목적, 작업 조건, 보상과 안전 기준을 확인하고 참여합니다. |
| 4 | `04-training-assignment.png` | 교육 이수와 현장 인력 배정 | 교육 가능한 청년을 검증된 Physical AI 현장 전문인력으로 연결합니다. |
| 5 | `05-web-preflight.png` | 현장 수집 전 웹 작업 조건 점검 | 동의, 촬영 범위, 개인정보 및 안전 요건을 작업 전에 확인합니다. |
| 6 | `06-web-collection.png` | 웹 기반 작업 데이터 수집 | 실제 작업 과정을 구간화하고 품질 정보를 붙여 검수 단계로 제출합니다. |
| 7 | `07-quality-review.png` | 데이터 품질·개인정보 검수 | 승인 또는 재작업 절차로 학습 데이터의 품질과 신뢰성을 관리합니다. |
| 8 | `08-dataset-library.png` | 업종별 Physical AI 데이터셋 탐색 | 식당, 동네마트, 숙박업 등 지역 생활 현장의 데이터셋을 제공합니다. |
| 9 | `09-dataset-detail.png` | 데이터셋 버전·출처·접근 관리 | 로봇 학습에 필요한 데이터의 계보와 사용 조건을 투명하게 제공합니다. |
| 10 | `10-work-compensation.png` | 청년의 웹 기반 활동·보상·역량 기록 | 단순 수집을 넘어 검수와 현장 운영 역량으로 성장하는 일자리 경로를 보여줍니다. |

## 이미지 스토리라인

`서비스 소개` → `현장 발견` → `작업 선택` → `교육·배정` → `사전 점검` → `데이터 수집` → `품질 검수` → `데이터셋 공개` → `로봇 학습 활용` → `청년의 보상·경력 축적`

## 시간이 부족할 때 우선 업로드할 8장

1. `01-robohood-overview.png`
2. `02-field-explorer.png`
3. `03-task-detail.png`
4. `04-training-assignment.png`
5. `06-web-collection.png`
6. `07-quality-review.png`
7. `08-dataset-library.png`
8. `10-work-compensation.png`

`05-web-preflight.png`와 `09-dataset-detail.png`는 정책·데이터 거버넌스의 구체성을 보강하는 화면이므로, 가능하면 10장 모두 제출하는 것을 권장합니다.
