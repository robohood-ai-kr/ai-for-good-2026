# Stitch 내보내기 원본 · v1

사용자가 제공한 네 ZIP을 제품별로 병합했습니다. 원본 다운로드 ZIP과 이 폴더의 `code.html`, `screen.png`를 덮어쓰지 않습니다.

| 제품 | 기본 묶음 | 나머지 묶음 | 합계 |
|---|---:|---:|---:|
| 제조업 중심 | 16 | 5 | 21 |
| 소상공인 중심 | 15 | 5 | 20 |

- `manufacturing/mf-01`–`mf-21`: 제조업 원본
- `small-business/sb-01`–`sb-20`: 소상공인 원본
- 각 제품의 `STITCH_DESIGN.md`: Stitch가 내보낸 참고 문서. 저장소 루트의 `DESIGN.md`나 MVP 명세를 대체하지 않습니다.
- `manifest.json`: 원본 ZIP 이름·SHA-256, 화면별 파일 해시, 병합 결과, 경고. 개인 Downloads 경로는 기록하지 않았습니다.

소상공인 `sb-01/screen.png`는 원본 ZIP부터 28바이트의 유효하지 않은 PNG입니다. 그대로 보존했으며 정상인 `code.html`로 앱을 빌드합니다. 이미지 복원이나 재생성을 했다는 뜻은 아닙니다.

원본 HTML은 실행용 앱이 아닙니다. 외부 스크립트·인라인 이벤트·미검증 문구가 포함되어 있으므로 실행은 저장소 루트의 `npm run dev`를 사용합니다. `scripts/import-stitch.py`는 경로 탈출·심볼릭 링크·누락·중복 충돌을 검사하며, 기존 원본이 다르면 덮어쓰지 않습니다.
